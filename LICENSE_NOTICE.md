The German Traffic Sign Recognition Benchmark (GTSRB) is **not included** in this repository or ZIP.

set by the dataset owners (Institut fuer Neuroinformatik, Ruhr-Universitaet Bochum). The build
environment of this package could not reach the source page, so the licence text could **not be

`DATASET_DOWNLOAD.md` before submitting. Always cite:

> J. Stallkamp, M. Schlipsing, J. Salmen, C. Igel. *Man vs. computer: Benchmarking machine learning
> algorithms for traffic sign recognition.* Neural Networks 32 (2012) 323-332.
